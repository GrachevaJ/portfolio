Проекты

Berry

Адаптивный интернет-магазин на HTML5, Sass и БЭМ. Реализована вёрстка под 3 разрешения с ретинизацией графики (WebP, SVG-спрайты), прогрессивное мобильное меню на JavaScript (работающее и без JS), интерактивная карта и автоматизация сборки через Gulp.

Сайт GitHub

Cryptostars

SPA-сервис для P2P-обмена криптовалюты. Реализована работа с REST API, сквозная фильтрация контрагентов, отображение точек наличного обмена на карте (Leaflet), двусторонний конвертер валют и кастомная валидация форм (Pristine) с учётом лимитов и балансов.

Сайт GitHub

Big Trip

SPA-планировщик маршрутов на нативном JavaScript (архитектура MVP). Реализован полный цикл работы с данными через REST API (CRUD), динамическая сортировка и фильтрация точек маршрута, интеграция календарей (Flatpickr) и автоматический расчёт стоимости и тайминга поездки.

Сайт GitHub

Escape Room

Веб-приложение для бронирования квестов на React и TypeScript. Реализованы многоуровневая фильтрация каталога, управление состоянием через Redux Toolkit, приватный роутинг с авторизацией по токену, валидация форм (React Hook Form) и выбор локаций на интерактивной карте Leaflet.

Сайт GitHub
